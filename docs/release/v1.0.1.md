# v1.0.1

我们很高兴地宣布 **`cedarv-license-manager-sdk` (Python)** 官方客户端 v1.0.1 正式发布！

这是 cedar-v 授权管控中枢的核心组件，为各类 Python 算法模型、B端软件及私有化部署场景提供了军工级的业务保护与授权全生命周期管理。

### 🚀 核心特性 (Features)

*   **硬件混合绑定**：全平台自动提取 MAC、CPU、Hostname 等底层硬件特征，真正实现“一机一码”防篡改。
*   **双重加密防护**：应用不可逆的非对称 RSA-PSS 验签与 AES-GCM 动态加密，保障本地授权文件的安全着陆。
*   **全场景激活支持**：
    *   **在线模式**：支持极简激活码，终端主动获取授权。
    *   **离线侧载**：支持 `AuthCode & Envelope` 脱机物理隔离环境下的秒级激活。
*   **实时安全心跳**：底层守护线程支持动态下发策略，当后台执行禁用、解绑操作时，客户端可实现毫秒级业务熔断。
*   **极简接入体验**：保持极低侵入性，开箱即用，已全面上传 PyPI。

### 📦 安装指南

开发者可以通过 `pip` 一键极速安装：

```bash
pip install cedarv-license-manager-sdk==1.0.1
```

### 💡 附加资源

*   **官方 GUI 体验客户端**：我们在源码中提供了基于 `Tkinter` 编写的演示客户端（`LMClientSimulator-win64`），欢迎在 `examples` 目录中打包体验其完整的阻断和授权交互流程。
*   **自动化流水线集成**：已完整集成基于 OIDC 的自动化 GitHub Actions 流水线，助力后续版本的持续集成和无秘钥安全发布。
